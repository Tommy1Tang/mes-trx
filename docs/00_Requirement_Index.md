## 2. 一期MVP范围标注

> 一期围绕"一个受控产品 + 一条典型产线 + 一个完整批记录闭环"建设最小合规闭环。
> 以 **配液称量 + 电子批记录** 为MVP核心。

**一期包含的需求模块**：MDM(L1)、BOM(L2)、ROUTE(L2)、MBR(L2)、RULE(L3)、CHG(L3)、ORDER(L4)、SCH(L4)、DISP(L4)、RPT(L5)、WEI(L5)、EBR(L5)、MON(L5)、EXC(L6)、QUA(L6)、CMP(L6)、SCADA(L7)、TRC(L8)、SAP(L9)、IF(L9)、RT(L0)

**一期暂缓的需求模块**：OEE(L7全量)、ENV(L7全量)、CC(L7全量)、CLN(L7全量)、SIM(L10)
