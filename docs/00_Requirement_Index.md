# MES 项目需求总索引
## 1. 需求分类规则
所有需求统一按模块分类，每个需求分配唯一ID，格式为：`REQ-[模块缩写]-[序号]`，模块缩写对照表：
| 模块 | 缩写 |
|------|------|
| 排产管理 | SCH |
| 生产订单 | ORDER |
| 物料管理 | MAT |
| 派工单管理 | DISP |
| 现场报工 | RPT |
| 电子批记录 | BATCH |
| 异常管理 | EXC |
| 订单关闭 | CLS |
| 系统集成 | INT |
需求状态说明：`待确认`/`已确认`/`开发中`/`测试中`/`已上线`
