# 系统架构与集成方案
## 1. 技术栈选型
完全继承现有RuoYi框架技术栈，无额外新增技术依赖：
- 后端：Spring Boot 2.7.x + MyBatis Plus + Redis + RocketMQ
- 前端：Vue 2.x + Element UI + uniapp(移动端)
- 数据库：PostgreSQL 16
- 部署：Docker + Kubernetes + 双活集群
- 合规：电子签名符合FDA 21 CFR Part 11，符合GMP要求

## 2. 系统集成方案
### 2.1 SAP集成
| 场景 | 方向 | 频率 | 协议 | 异常处理 |
|------|------|------|------|----------|
| 主数据同步 | SAP→MES | 每日凌晨1点 | RFC | 3次立即重试→延迟重试队列→24小时失败告警，每日对账 |
| 生产订单同步 | SAP→MES | 实时+每日批量 | RFC | 同上 |
| 投料过账 | MES→SAP | 实时 | RFC | 同上 |
| 报工过账 | MES→SAP | 实时 | RFC | 同上 |
| 库存同步 | MES↔SAP | 实时+每小时对账 | RFC | 同上 |
| 财务过账 | MES→SAP | 每日凌晨2点 | RFC | 同上 |

### 2.2 WMS集成
| 场景 | 方向 | 触发时机 | 协议 | 一致性保证 |
|------|------|----------|------|----------|
| 领料出库 | MES→WMS | 派工单确认后 | HTTP | 最终一致性，每日对账，异常数据人工处理 |
| 退料入库 | MES→WMS | 退料申请审核后 | HTTP | 同上 |
| 成品入库 | MES→WMS | 生产完工报工后 | HTTP | 同上 |
| 库存查询 | MES→WMS | 实时调用 | HTTP | 同上 |
| 扫码对接 | WMS→MES | 扫码完成后 | HTTP | 同上 |

### 2.3 OA集成
| 场景 | 方向 | 触发时机 | 协议 | 回调机制 |
|------|------|----------|------|----------|
| 异常流程触发 | MES→OA | 异常工单升级时 | Webhook | 30秒超时，3次重试，ACK确认机制 |
| 标签/说明书审核 | MES→OA | 标签模板变更时 | Webhook | 同上 |
| 偏差处理流程 | MES→OA | 质量偏差上报时 | Webhook | 同上 |
| 流程结果回调 | OA→MES | 流程结束时 | Webhook | 同上 |

### 2.4 思宇UDI系统集成
| 场景 | 方向 | 触发时机 | 协议 | 校验规则 |
|------|------|----------|------|----------|
| UDI码生成 | MES→思宇 | 生产订单下达时 | HTTP | 符合国家药监局UDI编码规范，唯一性、完整性校验 |
| UDI码回传 | 思宇→MES | UDI生成完成后 | Webhook | 同上 |
| UDI打印 | MES→思宇 | 包装工序打印时 | HTTP | 同上 |

## 3. 合规性设计
### 3.1 GMP合规
- 电子签名符合FDA 21 CFR Part 11要求
- 所有操作留痕，审计日志保留至少5年
- 数据不可篡改，修改需留痕并说明原因
- 支持导出符合GMP要求的电子批记录PDF
### 3.2 数据安全
- 敏感数据加密存储，传输采用HTTPS
- RBAC权限控制，数据按角色隔离
- 操作审计日志完整，支持追溯
- 备份策略：每日全量备份+增量备份，异地容灾
