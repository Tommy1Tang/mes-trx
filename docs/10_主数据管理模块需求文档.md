# 主数据管理模块需求文档（L1层）
## 1. 模块概述
负责定义工厂、组织、人员、物料、设备、仓储、班次、区域、公用工程等基础对象，是其他所有模块的根数据。主数据的准确性和完整性直接影响排产、派工、执行、追溯和合规各环节。

**架构层：** L1 主数据与资源基础层
**涉及表：** pro_plant_master、pro_workshop_master、pro_production_line_master、pro_work_center_master、pro_material_master、pro_equipment_master、pro_person_master、pro_work_center_person_map、pro_wc_equipment、pro_tooling_master、pro_fixture_master、pro_supplier_master、pro_warehouse_master、pro_storage_location_master、pro_shift、pro_calendar、pro_environment_area、pro_utility_system、pro_downtime_reason、pro_person_qualification

### 2.2 开发加载规则
1. 先读取 `00_Blueprint.md`、`00_Agent_Collaboration_Rules.md`、`IVD_MES整体开发口径.md`。
2. 按需求ID或功能卡ID读取本模块对应功能卡，例如 `rg "REQ-XXX-001" docs/30_Feature_Cards` 或 `rg "FC-XXX-001" docs/30_Feature_Cards`。
3. 只加载功能卡声明的相关表字段、接口小节和治理规范，禁止一次加载整个字段字典。
4. 若功能卡仍缺页面字段、交互或验收细节，先补卡再开发。

## 3. 核心流程

### 3.1 主数据创建流程
1. 业务人员提交主数据创建申请
2. 系统校验编码唯一性、必填字段完整性
3. 管理员审核确认
4. 数据生效，可供其他模块引用

### 3.2 主数据变更流程
1. 业务人员提交变更申请
2. 系统记录变更前后的值
3. 管理员审核确认
4. 数据更新，审计留痕

## 4. 关联关系
- 工厂 → 车间 → 产线 → 工作中心（层级关系）
- 工作中心 ↔ 人员（多对多，通过 pro_work_center_person_map）
- 工作中心 ↔ 设备（多对多，通过 pro_wc_equipment）
- 物料 → BOM → 工艺路线 → MBR模板（上下游依赖）
- 人员 → 人员资质（一对多）
- 设备 → SCADA设备映射（L7层关联）
