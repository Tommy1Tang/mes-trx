# MBR模板管理模块需求文档（L2层后半）
## 1. 模块概述
MBR（Master Batch Record，主批生产记录模板）是IVD受控生产的核心建模层，定义了产品从配液、称量、孵育、灌装、冻干到包装的全部受控执行步骤。MBR是执行模板，EBR（电子批记录）是实际证据，二者必须版本绑定。

MBR模板将BOM和工艺路线"降维"为车间可执行、可防错、可追溯的步骤序列，每个步骤包含参数、物料、设备、质控项和流转规则。

**架构层：** L2 产品、工艺与MBR模板层（后半部分）
**涉及表：** pro_mbr_header、pro_mbr_version、pro_mbr_phase、pro_mbr_step、pro_mbr_step_parameter、pro_mbr_step_material、pro_mbr_step_equipment、pro_mbr_step_quality、pro_mbr_step_transition、pro_mbr_rework_rule、pro_mbr_dynamic_param_rule、pro_mbr_hold_rule、pro_mbr_step_person_role、pro_mbr_alternative_process_rule、pro_outsource_operation_rule

## 3. 核心流程

### 3.1 MBR模板创建流程
1. 工艺工程师创建MBR头表，关联产品、BOM、工艺路线
2. 定义MBR阶段（配液/称量/孵育/灌装/包装等）
3. 在每个阶段下添加步骤，定义步骤属性
4. 为每个步骤定义参数、物料、设备、质控项
5. 定义步骤流转规则（顺序/分支/并行）
6. 定义返工规则、动态参数规则、Hold规则
7. 提交审核，审核通过后发布

### 3.2 MBR版本变更流程
1. 基于已发布版本创建新版本（复制）
2. 修改新版本的步骤/参数/物料/设备/质控
3. 提交审核，审核通过后发布新版本
4. 旧版本自动停用（或保留并行）
5. 记录版本变更原因和变更内容

### 3.3 MBR与工单绑定流程
1. 创建生产订单时选择MBR版本
2. 系统将MBR模板"实例化"为工单的执行步骤
3. 工单执行过程中严格按MBR步骤顺序执行
4. 每个步骤的实际执行数据记录到EBR

## 4. 合规要求
1. MBR版本发布后不可修改，变更必须创建新版本
2. MBR版本变更必须记录变更原因、变更内容、审批人
3. MBR模板的审核流程必须包含QA放行环节
4. MBR与EBR必须版本绑定，EBR不可脱离MBR独立存在

## 5. 与其他模块的关系
- BOM + 工艺路线 → MBR模板（L2层输入）
- MBR模板 → 生产订单（L4层，工单绑定MBR版本）
- MBR步骤 → EBR步骤记录（L5层，执行固化）
- MBR步骤参数 → EBR参数记录（L5层，参数固化）
- MBR步骤质控 → 检验结果/电子签名（L6层）
- MBR版本变更 → ECN/MBR发布记录（L3层）
- MBR执行上下文 → 运行时韧性（L0层）
