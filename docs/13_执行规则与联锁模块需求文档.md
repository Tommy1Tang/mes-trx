# 执行规则与联锁模块需求文档（L3层）
## 1. 模块概述
负责把L2层的工艺模型转成可执行的控制规则，并管理MBR版本发布、工程变更（ECN）、版本差异对比和运行中安全切换。本模块是"受控执行"的核心保障层。

**架构层：** L3 执行规则、联锁与变更控制层
**涉及表：** pro_execution_rule、pro_interlock_rule、pro_interlock_event、pro_device_command_log、pro_error_proofing_record、pro_mbr_release_record、pro_mbr_change_record、pro_ecn_order、pro_ecn_affected_object、pro_mbr_version_diff

## 3. 核心流程

### 3.1 执行规则配置流程
1. 工艺工程师定义执行规则（防错/校验/放行/阻断）
2. 将规则关联到MBR步骤或全局
3. 配置规则优先级和触发条件
4. 提交审核，审核通过后生效

### 3.2 联锁触发处理流程
1. 执行过程中联锁条件被触发
2. 系统自动阻断执行或暂停
3. 记录联锁事件
4. 通知相关人员处理
5. 授权人员确认解除联锁
6. 恢复执行或转入异常流程

### 3.3 ECN处理流程
1. PLM或内部发起ECN
2. 工艺工程师分析影响范围
3. 审批ECN
4. 受影响的MBR进入Safe Hold
5. 刷新运行中工单的MBR执行上下文
6. 记录ECN处理全过程

## 4. 合规要求
1. 执行规则和联锁规则的变更必须经过审批
2. 联锁事件记录不可删除、不可篡改
3. 防错校验记录必须保留至少5年
4. ECN处理全过程必须可追溯
5. MBR版本差异对比必须支持审计检查

## 5. 与其他模块的关系
- L2 MBR模板 → L3 执行规则（规则关联到MBR步骤）
- L3 联锁规则 → L5 现场执行（联锁在执行时触发）
- L3 防错记录 → L6 异常管理（防错不通过触发异常）
- L3 ECN → L0 运行时韧性（ECN触发上下文刷新）
- L3 MBR发布 → L2 MBR版本（发布状态流转）
