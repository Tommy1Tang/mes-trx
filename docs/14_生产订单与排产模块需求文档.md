# 生产订单与排产模块需求文档（L4层）
## 1. 模块概述
负责承接SAP生产订单、展开工单组件和工序实例、排产计划制定、配套生产计划和派工安排。本模块是执行层的上游入口，将SAP的计划转化为车间可执行的工单；对于IVD配套生产场景，还需要支持MES根据成品订单生成半成品配套订单，并调用SAP创建正式生产订单。

**架构层：** L4 计划订单与车间调度层
**涉及表：** pro_production_order、pro_order_component、pro_order_operation、pro_schedule_plan、pro_schedule_log、pro_shop_floor_dispatch

## 3. 核心流程

### 3.1 工单创建与下达流程
1. SAP生产订单同步到MES
2. 系统自动匹配MBR版本
3. 展开工单组件和工序实例
4. 校验物料齐套、MBR版本、产能
5. 预编译MBR执行上下文
6. 工单下达，进入执行阶段

### 3.2 排产流程
1. 系统收集待排产订单
2. 评估产能和资源齐套
3. 自动排产生成初步计划
4. 人工调整优化
5. 锁定排产计划
6. 下发到车间生成派工任务

### 3.3 派工流程
1. 车间主管查看排产计划
2. 系统根据工单工序、产品、物料、工作中心和模板绑定规则匹配派工单模板。
3. 系统从工单、BOM、MBR、生产文件和配套计划中带出模板字段值。
4. 车间主管补充分配人员、设备、班组和执行时间。
5. 派工任务下发到执行人员。
6. 执行人员扫码接收、开工、执行和完工。

### 3.4 配套生产与SAP反写流程
1. SAP正常运行MRP，形成成品计划订单、半成品计划订单、原料/包材采购申请和相关需求。
2. SAP将A1/A2等成品生产订单下发到MES。
3. MES在配套生产工作台生成`plan_no`，计算R1/R2/R3、校准品、质控品需求。
4. MES生成半成品订单草稿，计划员复核数量、日期、工厂、MRP区域、生产版本和批量规则。
5. MES通过Outbox调用SAP创建半成品生产订单。
6. SAP返回正式生产订单号，MES保存并绑定到本地订单和`plan_no`。
7. 半成品、校准品、质控品执行生产，完成联合量值溯源/赋值和质检解锁。
8. A1/A2成品灌装包装时按`plan_no`校验投料批次。
9. 下一次SAP MRP运行时，MES创建的SAP生产订单作为确定供应元素冲抵原半成品计划订单；必要时触发单物料MRP重算缩短重复供应窗口。

### 3.5 MRP冲抵关键约束
- R1/R2/R3、校准品、质控品必须正常参与SAP MRP，不能设置为ND。
- MES创建SAP生产订单时，基本开始日期、基本完成日期、需求日期应贴近成品投料需求，完工日期应早于成品灌装包装需要。
- 数量应考虑SAP批量规则、最小/最大批量、舍入值、安全库存、损耗率、容器规格和配液罐产能。
- 工厂、库存地点、MRP区域、生产版本、BOM可选项和Routing应与原MRP需求保持一致，否则可能不能稳定冲抵。
- 若SAP计划订单被人工固定、处于计划时界或受firming type影响，MRP可能不会自动删除或调整计划订单，需要提示计划员处理。
- 在下一次MRP运行前，SAP MD04可能短暂同时存在半成品计划订单和生产订单，系统应在配套计划看板中标识“已由MES创建生产订单覆盖”。

### 3.6 候选数据模型（待DBA治理评审）
- `pro_production_order` 候选扩展字段：`plan_no`、`local_request_no`、`sap_order_no`、`sap_sync_status`、`sap_message`。
- 建议新增配套计划主表，用于记录`plan_no`、计划状态、来源成品订单范围、创建人、审核人和关闭状态。
- 建议新增配套计划订单关系表，用于绑定成品订单、半成品订单、校准品订单、质控品订单和SAP订单号。
- 派工单配置化候选新增表：派工单模板表、派工单模板分区表、派工单模板字段表、模板工序绑定表、派工单实例字段值表。
- 上述候选模型仅作为需求口径，字段字典和DDL必须由DBA按数据模型治理规范评审后落地。

## 4. 与其他模块的关系
- SAP订单 → L4 生产工单（订单同步）
- L2 BOM → L4 工单组件（组件展开）
- L2 工艺路线 → L4 工单工序（工序展开）
- L2 MBR模板 → L4 工单MBR绑定
- L0 MBR执行上下文 → L4 工单下达预编译
- L4 排产 → L5 现场执行（派工下发）
- L1 主数据 → L4 产能评估（资源齐套）
- L9 SAP集成 → L4 配套计划（MES创建SAP半成品生产订单）
- L8 批次追溯 → L4 配套计划（`plan_no`贯穿批次和族谱）
