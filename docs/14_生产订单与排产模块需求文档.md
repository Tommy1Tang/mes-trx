# 生产订单与排产模块需求文档（L4层）
## 1. 模块概述
负责承接SAP生产订单、展开工单组件和工序实例、排产计划制定和派工安排。本模块是执行层的上游入口，将SAP的计划转化为车间可执行的工单。

**架构层：** L4 计划订单与车间调度层
**涉及表：** pro_production_order、pro_order_component、pro_order_operation、pro_schedule_plan、pro_schedule_log、pro_shop_floor_dispatch

## 3. 核心流程

### 3.1 工单创建与下达流程
1. SAP生产订单同步到MES
2. 系统自动匹配MBR版本
3. 展开工单组件和工序实例
4. 校验物料齐套、MBR版本、产能
5. 预编译MBR执行上下文
6. 工单下达，进入执行阶段

### 3.2 排产流程
1. 系统收集待排产订单
2. 评估产能和资源齐套
3. 自动排产生成初步计划
4. 人工调整优化
5. 锁定排产计划
6. 下发到车间生成派工任务

### 3.3 派工流程
1. 车间主管查看排产计划
2. 分配人员和设备到派工任务
3. 派工任务下发到执行人员
4. 执行人员开始作业

## 4. 与其他模块的关系
- SAP订单 → L4 生产工单（订单同步）
- L2 BOM → L4 工单组件（组件展开）
- L2 工艺路线 → L4 工单工序（工序展开）
- L2 MBR模板 → L4 工单MBR绑定
- L0 MBR执行上下文 → L4 工单下达预编译
- L4 排产 → L5 现场执行（派工下发）
- L1 主数据 → L4 产能评估（资源齐套）
