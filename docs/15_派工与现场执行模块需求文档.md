# 派工与现场执行模块需求文档（L4+L5层）
## 1. 模块概述
负责记录现场真实执行过程，包括工序执行、报工、人工设备投入、过程跟踪和过程监控。本模块是"受控执行"的直接载体，每个执行动作都必须留痕。

**架构层：** L4 计划订单与车间调度层（派工）+ L5 现场执行、称量与电子批记录层（执行/报工/跟踪/监控）
**涉及表：** pro_shop_floor_dispatch、pro_operation_execution、pro_production_report、pro_report_labor、pro_report_equipment、pro_operation_tracking、pro_process_monitor_session、pro_process_monitor_summary

## 3. 核心流程

### 3.1 现场执行流程
1. 执行人员接收派工任务
2. 扫码确认开工，系统校验人员/设备/物料
3. 按MBR步骤顺序执行：
   a. 确认工艺参数
   b. 扫码投料
   c. 记录执行数据
   d. 执行检验/复核
4. 扫码确认完工
5. 填报产量和工时
6. 提交报工审核
7. 审核通过后数据同步SAP

### 3.2 过程监控流程
1. 过程开始时创建监控会话
2. SCADA/ThingsBoard持续采集数据
3. MES固化关键值、摘要、告警
4. 过程结束时关闭会话
5. 摘要数据关联到EBR

## 4. 与其他模块的关系
- L4 派工 → L5 现场执行（派工下发到执行）
- L2 MBR步骤 → L5 工序执行（按MBR步骤执行）
- L3 联锁规则 → L5 工序执行（执行时触发联锁）
- L5 报工 → L9 SAP集成（报工回传SAP）
- L5 过程监控 → L7 SCADA集成（采集数据来源）
- L5 工序执行 → L5 EBR（执行数据固化到EBR）
- L5 工序执行 → L5 称量投料（执行中的投料动作）
