# 称量与投料模块需求文档（L5层，一期MVP重点）
## 1. 模块概述
负责生产过程中的工序级领料、线边仓库存、物料投料和称量管理，是IVD配液称量场景的核心模块。本模块覆盖从生产领料申请、WMS移库到线边仓、线边仓投料消耗、退料盘点、物料扫码、批次校验、电子天平点检、称量记录到投料确认的全过程，确保投料的准确性和合规性。

**架构层：** L5 现场执行、称量与电子批记录层
**涉及表：** pro_operation_consumption、pro_operation_return、pro_weighing_record、pro_scale_device_check、pro_weighing_audit_log；线边仓与领退料候选表待DBA评审
**一期MVP：** 本模块是一期MVP的核心，必须优先实现

## 3. 核心流程

### 3.1 投料称量流程（一期MVP核心）
1. 执行人员扫码确认工单/工序
2. 系统显示该步骤需要投放的物料清单
3. 执行人员选择物料，扫码物料条码
4. 系统校验物料批次、有效期、状态
5. 校验通过后，执行人员将物料放到电子天平
6. 系统校验天平点检状态和校准有效期
7. 天平自动采集称量数据（或人工录入）
8. 系统判定称量结果是否在目标值±允差范围内
9. 称量合格：确认投料，记录称量数据
10. 称量不合格：触发异常，等待处理（补称/重称/放行）
11. 关键物料需要复核员复核确认
12. 投料确认后实时过账SAP

### 3.2 退料流程
1. 生产人员扫码剩余物料
2. 系统自动生成退料单
3. 车间主管审核
4. 审核通过后MES通过Outbox发送WMS退料请求
5. WMS完成实物退料并回传结果
6. MES冲减线边仓库存并记录库存流水
7. 系统按需同步SAP更新库存或消耗差异

### 3.3 工序级领料与线边仓入账流程
1. 生产按工序/MBR Step在MES发起领料申请。
2. MES校验工单、工序、物料、批次策略和替代料规则。
3. MES通过Outbox发送领料申请到WMS。
4. WMS按库房规则拣配和移库，可合并相同物料相同批次。
5. WMS回传移库结果，MES保存WMS结果与原始工序需求映射。
6. MES建立线边仓库存台账和库存流水。
7. 投料时从线边仓库存中扣减，单件码物料逐码扣减。

### 3.4 候选数据模型（待DBA治理评审）
- 生产领料：`pro_material_requisition`、`pro_material_requisition_item`。
- WMS移库结果：`pro_wms_transfer_result`、`pro_wms_transfer_result_item`、`pro_material_requisition_wms_map`。
- 线边仓库存：`pro_lineside_inventory`、`pro_lineside_inventory_unit`、`pro_lineside_inventory_txn`。
- 物料分发/单件码投料：`pro_material_distribution`、`pro_material_distribution_item`、`pro_operation_consumption_unit`。
- 生产退料：`pro_lineside_return`、`pro_lineside_return_item`。
- 盘点预警：`pro_lineside_stocktake`、`pro_lineside_stocktake_item`、`pro_lineside_stocktake_unit`、`pro_inventory_warning_rule`、`pro_inventory_warning_event`。
- 物料平衡：`pro_material_balance_rule`、`pro_material_balance_record`、`pro_material_balance_item`、`pro_material_balance_review`。
- 上述候选模型仅作为需求口径，字段字典和DDL必须由DBA按数据模型治理规范评审后落地。

## 4. 合规要求
1. 所有投料必须扫码，禁止人工输入物料信息
2. 称量数据必须关联电子天平设备信息和校准状态
3. 称量记录不可篡改，修改必须走审计流程
4. 称量审计日志保留至少5年
5. 关键物料称量必须双人复核
6. 电子天平点检记录必须保留，作为批放行证据

## 5. 与其他模块的关系
- L2 MBR步骤物料 → L5 称量投料（物料定义和允差）
- L2 MBR步骤设备 → L5 天平点检（天平设备要求）
- L3 联锁规则 → L5 称量校验（称量联锁）
- L5 称量投料 → L5 EBR（称量数据固化到EBR）
- L5 称量投料 → L9 SAP集成（投料过账回传）
- L5 称量异常 → L6 异常管理（异常记录）
- L9 WMS集成 → L5 线边仓（移库与退料回传）
- L8 批次追溯 → L5 线边仓（批次/单件码状态追溯）
- L6 合规审计 → L5 线边仓（盘点差异、库存调整、关键退料复核留痕）
