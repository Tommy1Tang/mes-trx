# 称量与投料模块需求文档（L5层，一期MVP重点）
## 1. 模块概述
负责生产过程中的物料投料和称量管理，是IVD配液称量场景的核心模块。本模块覆盖从物料扫码、批次校验、电子天平点检、称量记录到投料确认的全过程，确保投料的准确性和合规性。

**架构层：** L5 现场执行、称量与电子批记录层
**涉及表：** pro_operation_consumption、pro_operation_return、pro_weighing_record、pro_scale_device_check、pro_weighing_audit_log
**一期MVP：** 本模块是一期MVP的核心，必须优先实现

## 3. 核心流程

### 3.1 投料称量流程（一期MVP核心）
1. 执行人员扫码确认工单/工序
2. 系统显示该步骤需要投放的物料清单
3. 执行人员选择物料，扫码物料条码
4. 系统校验物料批次、有效期、状态
5. 校验通过后，执行人员将物料放到电子天平
6. 系统校验天平点检状态和校准有效期
7. 天平自动采集称量数据（或人工录入）
8. 系统判定称量结果是否在目标值±允差范围内
9. 称量合格：确认投料，记录称量数据
10. 称量不合格：触发异常，等待处理（补称/重称/放行）
11. 关键物料需要复核员复核确认
12. 投料确认后实时过账SAP

### 3.2 退料流程
1. 生产人员扫码剩余物料
2. 系统自动生成退料单
3. 车间主管审核
4. 审核通过后物料退回仓库
5. 系统同步WMS和SAP更新库存

## 4. 合规要求
1. 所有投料必须扫码，禁止人工输入物料信息
2. 称量数据必须关联电子天平设备信息和校准状态
3. 称量记录不可篡改，修改必须走审计流程
4. 称量审计日志保留至少5年
5. 关键物料称量必须双人复核
6. 电子天平点检记录必须保留，作为批放行证据

## 5. 与其他模块的关系
- L2 MBR步骤物料 → L5 称量投料（物料定义和允差）
- L2 MBR步骤设备 → L5 天平点检（天平设备要求）
- L3 联锁规则 → L5 称量校验（称量联锁）
- L5 称量投料 → L5 EBR（称量数据固化到EBR）
- L5 称量投料 → L9 SAP集成（投料过账回传）
- L5 称量异常 → L6 异常管理（异常记录）
