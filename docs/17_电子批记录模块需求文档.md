# 电子批记录模块需求文档（L5层，一期MVP重点）
## 1. 模块概述
EBR（Electronic Batch Record，电子批记录）是MBR模板的执行证据。每个工单执行时，系统根据MBR模板生成EBR，记录每个步骤的实际执行情况，包括开始/结束时间、执行人、设备、参数实际值、检验结果、复核签名等。EBR是GMP合规的核心证据。

**架构层：** L5 现场执行、称量与电子批记录层
**涉及表：** pro_ebr_header、pro_ebr_step_record、pro_ebr_param_record、pro_batch_review、pro_line_clearance_check
**一期MVP：** 本模块是一期MVP的核心，必须优先实现

## 3. 核心流程

### 3.1 EBR执行流程（一期MVP核心）
1. 工单下达时自动创建EBR头
2. 执行人员按MBR步骤顺序执行：
   a. 执行步骤操作
   b. 记录参数实际值（人工/自动采集）
   c. 执行检验/复核
   d. 电子签名确认
3. 每个步骤完成后记录到EBR步骤记录
4. 所有步骤完成后提交EBR
5. 车间主管审核
6. 质量工程师审核
7. QA放行，电子签名
8. 批记录归档
9. 支持导出PDF

### 3.2 清场流程
1. 换批/换品种前执行清场检查
2. 检查上批次物料是否清除
3. 检查设备是否清洁
4. 检查标签/包材是否正确
5. 检查环境是否达标
6. 清场通过后才能开工
7. 清场记录留存

## 4. 合规要求（FDA 21 CFR Part 11）
1. EBR数据不可篡改，修改必须留痕
2. 电子签名必须绑定用户、角色、动作、对象、时间、原因
3. 签名前必须重新认证，不能仅依赖已登录会话
4. 审计日志保留至少5年
5. 批记录导出格式符合GMP要求
6. 所有关键操作必须有电子签名

## 5. 与其他模块的关系
- L2 MBR模板 → L5 EBR（模板→证据）
- L2 MBR步骤 → L5 EBR步骤记录（步骤定义→步骤执行）
- L2 MBR步骤参数 → L5 EBR参数记录（参数定义→参数固化）
- L5 称量投料 → L5 EBR（称量数据固化到EBR）
- L5 工序执行 → L5 EBR（执行数据固化到EBR）
- L6 电子签名 → L5 EBR（签名绑定到EBR）
- L6 审计追踪 → L5 EBR（审计记录覆盖EBR）
- L6 异常/偏差 → L5 EBR（偏差关联到EBR）
