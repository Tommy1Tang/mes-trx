# 订单关闭管理模块需求文档
## 1. 模块概述
负责生产订单完成后的关闭流程管理，包括完工确认、合规校验、自动关闭、差异分析、数据归档，确保订单关闭的合规性和数据准确性。

## 3. 核心流程
### 3.1 订单自动关闭流程
1. 生产最后一道工序报工完成，成品入库
2. 质量检验完成，所有检验合格
3. 系统自动运行订单校验：
   - 所有工序投料完成
   - 所有物料已退库
   - 所有报工完成，工时完整
   - 所有异常已闭环
   - 收率在95%-105%范围内
4. 所有校验项通过，系统自动关闭订单
5. 自动生成差异分析报表
6. 自动归集成本到SAP
7. 订单数据自动归档
### 3.2 异常订单人工关闭流程
1. 系统校验不通过或收率超出范围，订单进入待人工审核列表
2. 业务助理审核异常原因，判断是否符合关闭条件
3. 不符合关闭条件的退回相关人员整改
4. 符合关闭条件的确认关闭订单
5. 后续流程同自动关闭流程
## 4. 订单状态说明
| 状态 | 说明 |
|------|------|
| 生产中 | 订单正在生产过程中 |
| 待校验 | 生产完成，正在进行关闭前校验 |
| 待审核 | 校验不通过或收率异常，待人工审核 |
| 已关闭 | 订单已正常关闭 |
| 重新开启 | 已关闭订单被重新开启，修改数据中 |
