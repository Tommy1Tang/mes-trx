# 异常管理与合规审计模块需求文档（L6层）
## 1. 模块概述
负责承接检验结果、不良品、异常事件、处置闭环、电子签名和审计追踪，是IVD合规闭环的核心层。本模块确保所有影响批放行的数据都能解释来源、责任人、时间、版本和修改历史。

**架构层：** L6 质量异常与合规审计层
**涉及表：** pro_defect_code_master、pro_production_defect、pro_inspection_result、pro_nc_handling、pro_exception_record、pro_exception_category、pro_exception_escalation、pro_e_signature_record、pro_audit_trail

## 3. 核心流程

### 3.1 异常处理流程
1. 生产人员发现异常，快速上报
2. 系统根据异常类型自动派发
3. 处理人接异常，分析原因
4. 采取处理措施（临时措施/根本原因分析）
5. 处理结果验证
6. 异常关闭
7. 经验沉淀到知识库

### 3.2 电子签名流程
1. 用户执行需要签名的操作
2. 系统弹出签名认证窗口
3. 用户输入密码或进行生物认证
4. 系统记录签名信息（用户/角色/动作/对象/时间/原因）
5. 签名记录保存到pro_e_signature_record

### 3.3 审计追踪流程
1. 用户执行关键操作（新增/修改/删除/复核/放行）
2. 统一审计组件自动记录审计事件
3. 审计记录写入pro_audit_trail
4. 审计记录不可修改，只追加

### 3.4 量值溯源审核与质检解锁流程
1. 系统检查同一`plan_no`下R1/R2/R3、校准品、质控品生产完成状态。
2. 质量工程师发起联合量值溯源/赋值审核，审核对象关联参与批次、参考品/标准品、仪器、方法、靶值和不确定度。
3. 审核通过后，系统更新配套体系解锁状态。
4. 系统允许相关半成品、校准品、质控品、成品进入质检或后续灌装放行。
5. 审核驳回或未完成时，系统阻断质检解锁并记录审计追踪。

## 4. 合规要求
1. 电子签名符合FDA 21 CFR Part 11要求
2. 审计日志保留至少5年
3. 所有影响批放行的数据都必须有审计记录
4. 电子签名不可伪造、不可篡改
5. 审计记录不可删除、不可修改

- L4 配套计划 → L6 质量管理（`plan_no`驱动质检解锁）
