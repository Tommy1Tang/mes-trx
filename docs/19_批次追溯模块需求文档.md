# 批次追溯模块需求文档（L8层）
## 1. 模块概述
负责记录来料、批次、序列号、在制品、成品和批次/序列号谱系，用于正向追踪和反向召回。批次追溯是IVD合规的核心能力，必须支持从成品到原料的全链路追溯。

**架构层：** L8 追溯仓储与批次族谱层
**涉及表：** pro_material_lot、pro_goods_receipt、pro_goods_receipt_item、pro_serial_number、pro_wip_lot、pro_wip_lot_tracking、pro_finished_good_lot、pro_finished_good_serial、pro_lot_genealogy、pro_serial_genealogy

## 3. 核心流程

### 3.1 批次追溯流程
1. 质量工程师输入批次号
2. 系统查询批次族谱
3. 正向追踪：展示该批次原料→所有使用该原料的成品
4. 反向召回：展示该成品→所有使用的原料批次
5. 支持导出追溯报告

### 3.2 来料批次管理流程
1. 物料到货，仓库扫码收货
2. 系统自动创建物料批次记录
3. 触发来料检验流程
4. 检验合格后批次状态更新为"可用"
5. 物料投料时关联批次信息
6. 批次使用完后状态更新为"已用完"

### 3.3 配套计划追溯流程
1. MES按成品订单生成`plan_no`，并创建R1/R2/R3、校准品、质控品订单。
2. 半成品和质控相关物料生产完成后，WIP批次继承订单`plan_no`。
3. 同一`plan_no`下R1/R2/R3、校准品、质控品均完成后，系统允许启动联合量值溯源/赋值。
4. 赋值审核通过后，系统解锁对应半成品、校准品、质控品和成品的质检或灌装后续动作。
5. 成品投料时，系统校验当前成品工单`plan_no`与扫描半成品批次`plan_no`一致。
6. 追溯查询支持按`plan_no`展示成品、半成品、校准品、质控品、赋值任务和检验记录。

### 3.4 候选数据模型（待DBA治理评审）
- `pro_wip_lot`、`pro_finished_good_lot`候选扩展字段：`plan_no`。
- 建议新增量值溯源任务表，用于记录任务号、`plan_no`、状态、方法、仪器、参考品/标准品批次、靶值、不确定度、报告号、审核人和审核时间。
- 建议新增量值溯源任务批次明细表，用于记录R1/R2/R3、校准品、质控品、参考品/标准品等参与批次。
- 线边仓相关追溯候选表沿用线边仓候选模型：线边仓库存表、线边仓单件码库存表、线边仓库存流水表、领料需求与WMS移库映射表、投料单件码明细表。
- 上述候选模型仅作为需求口径，字段字典和DDL必须由DBA按数据模型治理规范评审后落地。

## 4. 合规要求
1. 批次追溯必须覆盖从原料到成品的全链路
2. 追溯数据不可篡改
3. 追溯查询必须在10秒内响应
4. 追溯报告必须支持导出，满足药监检查要求
5. 批次效期管理必须严格，过期物料禁止使用

## 5. 与其他模块的关系
- L1 物料主数据 → L8 物料批次（物料基础信息）
- L5 投料 → L8 批次族谱（投料时建立族谱关系）
- L5 EBR → L8 批次追溯（EBR关联批次信息）
- L6 检验结果 → L8 来料批次（检验结果关联批次）
- L9 SAP集成 → L8 批次同步（SAP批次同步到MES）
- L8 批次 → L8 族谱（批次间关系）
- L4 配套计划 → L8 批次追溯（`plan_no`贯穿订单、批次和族谱）
- L6 质量管理 → L8 量值溯源（赋值审核与质检解锁）
- L5 线边仓 → L8 批次追溯（线边仓库存、库存流水和单件码状态）
- L9 WMS集成 → L8 批次追溯（WMS移库结果与工序需求映射）
