# 订单关闭管理模块需求文档（L4+L5层收尾）
## 1. 模块概述
负责生产订单完成后的关闭流程管理，包括完工确认、合规校验、EBR审核前置校验、自动关闭、差异分析、数据归档。确保订单关闭的合规性和数据准确性。

**架构层：** L4 计划订单与车间调度层 + L5 现场执行层（收尾）
**涉及表：** pro_production_order（状态更新）、pro_ebr_header（审核前置）

## 3. 核心流程

### 3.1 订单关闭流程
1. 所有工序执行完成
2. 所有报工数据审核通过
3. 所有EBR审核放行
4. 所有投料确认并过账SAP
5. 所有异常关闭
6. 所有质检完成
7. 系统自动计算收率
8. 收率异常时要求填写原因
9. 系统自动校验所有关闭条件
10. 条件全部通过，订单自动关闭
11. EBR自动归档
12. 财务成本归集到SAP
13. 生成差异分析报表

### 3.2 订单重新开启流程
1. 提交订单重新开启申请
2. 填写开启原因
3. 审批通过
4. 订单状态更新为"执行中"
5. 可重新报工、投料、修改EBR
6. 修改完成后重新关闭

## 4. 与其他模块的关系

- L5 报工 → L22 报工校验（报工数据完整性）

- L5 投料 → L22 投料校验（投料数据完整性）
- L6 异常 → L22 异常校验（异常关闭状态）
- L9 SAP → L22 成本归集（财务数据回传）
