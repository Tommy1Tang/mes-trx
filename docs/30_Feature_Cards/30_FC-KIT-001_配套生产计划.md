# FC-KIT-001 配套生产计划

## 1. 加载入口
- 路由文档：`14_生产订单与排产模块需求文档.md`
- 原始小节：`2.4 配套生产计划`
- 关联需求：REQ-KIT-001、REQ-KIT-002、REQ-KIT-003、REQ-KIT-004、REQ-KIT-005、REQ-KIT-006、REQ-KIT-007、REQ-KIT-008
- 候选关联表：pro_production_order、pro_order_component、pro_order_operation、pro_schedule_plan、pro_schedule_log、pro_shop_floor_dispatch
- 架构层：L4 计划订单与车间调度层

## 2. 功能范围
本功能卡承接下列需求，用于开发 Agent 按功能包进行最小上下文加载。模块边界以路由文档为准，字段落地以数据字典和DBA治理结果为准。

## 3. 需求明细
| 需求ID | 需求名称 | 优先级 | 业务规则 | 验收标准 | 涉及角色 |
|--------|----------|--------|----------|----------|----------|
| REQ-KIT-001 | 配套计划号生成 | P0 | MES在配套生产工作台中为一组相关成品订单生成唯一`plan_no`/Campaign，作为成品、半成品、校准品、质控品共同执行和追溯的业务主线 | 同一配套体系内订单均绑定同一`plan_no` | 生产计划员 |
| REQ-KIT-002 | 配套需求计算 | P0 | MES基于A1/A2等成品订单、BOM/MBR、批量规则、损耗率、容器规格和配液罐产能，计算R1/R2/R3、校准品、质控品需求 | 计算结果可追溯、可人工复核 | 生产计划员 |
| REQ-KIT-003 | 半成品订单草稿 | P0 | MES本地先生成半成品生产订单草稿，记录内部请求号、物料、数量、计划日期、工厂、MRP区域、生产版本、`plan_no`和来源成品订单 | 草稿可查看、可调整、可提交SAP | 生产计划员 |
| REQ-KIT-004 | 创建SAP半成品生产订单 | P0 | MES不执行“计划订单转生产订单”，而是调用SAP创建R1/R2/R3、校准品、质控品正式生产订单；SAP返回正式订单号后，MES以SAP订单号作为最终工单号 | SAP订单创建成功后本地工单号与SAP订单号一致 | 系统自动 |
| REQ-KIT-005 | MRP冲抵口径管理 | P0 | SAP半成品计划订单继续保留并参与MRP；MES创建的SAP生产订单作为确定供应元素，由SAP下一次MRP净需求计算冲抵、调整或取消原计划订单 | 文档和看板能解释短暂重复供应窗口 | 计划员/接口运维 |
| REQ-KIT-006 | 配套订单绑定 | P0 | 成品订单、半成品订单、校准品订单、质控品订单均绑定同一`plan_no`，用于执行防错、量值溯源、质检解锁、追溯和成本分析 | 可按`plan_no`查询完整订单树 | 生产计划员 |
| REQ-KIT-007 | 配套计划差异提示 | P0 | 当MES创建数量、日期、工厂、MRP区域、生产版本与SAP MRP计划不一致时，系统提示差异并要求记录原因 | 差异可见、可审计 | 生产计划员 |
| REQ-KIT-008 | 配套计划追踪看板 | P0 | 支持按`plan_no`查看成品订单、半成品订单、SAP创建状态、MRP冲抵状态、量值溯源状态、质检解锁状态和投料防错状态 | 关键状态一屏可追踪 | 生产计划员 |

## 4. 开发级补充清单
- 页面入口：待前端开发前由产品/架构确认。
- 查询条件：开发前按字段字典和业务高频检索项补齐。
- 新增/编辑规则：以本卡需求明细、字段字典必填/长度/dict_code为准。
- 删除/停用规则：涉及已被工单、批次、审计或接口引用的数据，默认只允许停用，不允许物理删除。
- 权限点：遵循RuoYi权限体系，权限标识以接口规范为准。
- 审计追踪：影响受控生产、放行、追溯和接口补偿的数据必须留痕。

## 5. 验收用例骨架
- 正向：必填字段完整、编码唯一、状态有效时可保存。
- 反向：编码重复、必填缺失、引用对象不存在或状态不可用时必须阻断。
- 权限：无对应权限时不可新增、编辑、删除/停用或导出。
- 审计：新增、修改、停用、审核、导入等关键动作可追溯。
