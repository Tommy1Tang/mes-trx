# 变更记录规范

## 目标

所有数据模型变更都要可追踪、可回滚、可评审。

## 需要记录的变更

- 新增表
- 删除表
- 修改表名
- 新增字段
- 删除字段
- 修改字段类型
- 修改字段长度
- 修改是否必填
- 修改默认值
- 修改主键、外键、唯一键
- 新增或修改字典项
- 新增索引

## 变更编号规则

建议格式：

```text
DM-YYYYMMDD-序号
```

示例：

```text
DM-20260430-001
```

## 变更记录模板

```markdown
## 变更编号：DM-YYYYMMDD-001

### 变更类型
新增表 / 新增字段 / 修改字段 / 删除字段 / 新增字典项 / 修改外键 / 新增索引

### 需求来源
说明来自哪个模块、需求编号或评审意见。

### 变更内容
- 新增表：
- 新增字段：
- 修改字段：
- 新增字典：

### 影响范围
- 影响模块：
- 影响接口：
- 影响报表：
- 影响历史数据：
- 是否需要数据迁移：

### 兼容策略
说明是否向下兼容、是否保留旧字段、是否需要脚本迁移。

### 校验结果
- 主键校验：
- 外键校验：
- 重复字段校验：
- 字典编码校验：
- 字段说明校验：

### 评审结论
通过 / 待调整 / 暂缓

### 备注
补充说明。
```

## 文件建议

建议在本目录下维护：

```text
MES数据模型变更记录.md
```

如果变更很多，也可以按月份拆分：

```text
changes/2026-04.md
changes/2026-05.md
```

## 变更前后备份

修改核心 CSV 前建议生成备份：

```text
MES系统基础表逐字段数据字典_变更前备份_YYYYMMDDHHmm.csv
```

## AI Coding 要求

AI 执行数据模型变更时，必须在最终回复里说明：

- 修改了哪些文件
- 新增或修改了哪些表
- 新增或修改了多少字段
- 校验结果
- 剩余风险
