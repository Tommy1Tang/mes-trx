# MES数据模型治理规范索引

## 用途

本目录用于管理 MES 系统基础表、字段、字典、变更和 AI Coding 上下文加载规范。

后续新增表、字段、字典项或生成 SQL、实体类、Mapper、页面时，优先读取本索引，再按任务加载对应专题文件，避免一次性塞入过多上下文。

## 推荐加载顺序

### 场景一：判断是否要新增表

1. 读取本文件。
2. 读取 [01_AI渐进式加载指南.md](01_AI渐进式加载指南.md)。
3. 读取 [02_新增表规范.md](02_新增表规范.md)。
4. 读取 [MES系统基础表清单_按优先级.md](../MES系统基础表清单_按优先级.md)。
5. 需要字段细节时，再读取 [MES系统基础表逐字段数据字典_按优先级.csv](../MES系统基础表逐字段数据字典_按优先级.csv) 的相关表。

### 场景二：给已有表新增字段

1. 读取本文件。
2. 读取 [03_新增字段规范.md](03_新增字段规范.md)。
3. 读取 [04_字典项管理规范.md](04_字典项管理规范.md)。
4. 只读取目标表在逐字段数据字典中的字段行。
5. 修改后执行 [06_校验规则清单.md](06_校验规则清单.md)。

### 场景三：生成建表 SQL

1. 读取本文件。
2. 读取 [06_校验规则清单.md](06_校验规则清单.md)。
3. 读取 [07_代码生成前检查清单.md](07_代码生成前检查清单.md)。
4. 读取 [09_PostgreSQL数据库落地规范.md](09_PostgreSQL数据库落地规范.md)。
5. 读取 [MES系统基础表逐字段数据字典_按优先级_pgsql.csv](../MES系统基础表逐字段数据字典_按优先级_pgsql.csv)。
6. 只有做跨库逻辑评审时，才读取 [MES系统基础表逐字段数据字典_按优先级.csv](../MES系统基础表逐字段数据字典_按优先级.csv)。

### 场景四：做数据模型评审

1. 读取本文件。
2. 读取 [02_新增表规范.md](02_新增表规范.md)、[03_新增字段规范.md](03_新增字段规范.md)、[06_校验规则清单.md](06_校验规则清单.md)。
3. 按模块读取表清单和逐字段数据字典。

### 场景五：做运行时架构或集成开发

1. 读取本文件。
2. 读取 [08_MES运行时架构约束与数据落地规范.md](08_MES运行时架构约束与数据落地规范.md)。
3. 涉及新增表时读取 [02_新增表规范.md](02_新增表规范.md)。
4. 涉及新增字段时读取 [03_新增字段规范.md](03_新增字段规范.md) 和 [04_字典项管理规范.md](04_字典项管理规范.md)。
5. 只读取运行时支撑、MBR/EBR、SCADA、接口相关表的字段行。

## 维护原则

- `MES系统基础表逐字段数据字典_按优先级.csv` 是逻辑字段评审来源。
- `MES系统基础表逐字段数据字典_按优先级_pgsql.csv` 是 PostgreSQL 建表落地的字段级唯一来源。
- `MES系统基础表清单_按优先级.md` 是表级唯一事实来源。
- 运行时架构、缓存、消息、CDC、Outbox、Safe Hold、SCADA 数据分层以 [08_MES运行时架构约束与数据落地规范.md](08_MES运行时架构约束与数据落地规范.md) 为准。
- PostgreSQL 类型、索引、分区、JSONB 和 DDL 生成以 [09_PostgreSQL数据库落地规范.md](09_PostgreSQL数据库落地规范.md) 为准。
- 所有新增表、字段、字典项都要留下变更记录。
- AI Coding 时优先加载最小上下文，避免一次性读取全部文件。
- 生成 SQL 或代码前必须先通过校验规则。
