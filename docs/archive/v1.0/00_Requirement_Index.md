# MES 项目需求总索引
## 1. 需求分类规则
所有需求统一按模块分类，每个需求分配唯一ID，格式为：`REQ-[模块缩写]-[序号]`，比如`REQ-DISPATCH-001`（派工单模块第1个需求）
### 模块缩写对照表
| 模块 | 缩写 |
|------|------|
| 排产管理 | SCHEDULE |
| 生产订单 | ORDER |
| 物料管理 | MATERIAL |
| 派工单管理 | DISPATCH |
| 现场报工 | REPORT |
| 电子批记录 | BATCH |
| 异常管理 | EXCEPTION |
| 系统集成 | INTEGRATION |

## 3. 需求状态说明
| 状态 | 说明 |
|------|------|
| 待确认 | 需求已提出，待客户确认 |
| 已确认 | 需求已确认，待开发排期 |
| 开发中 | 正在开发实现 |
| 测试中 | 开发完成，测试验证中 |
| 已上线 | 已上线运行 |
| 已拒绝 | 需求不合理，拒绝实现 |

---
## 4. 新增需求规则
所有新增需求必须先在本索引中登记，分配唯一ID后才能进入开发流程，禁止未登记的需求直接开发。
