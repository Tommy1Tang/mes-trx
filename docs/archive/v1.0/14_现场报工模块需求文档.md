# 现场报工模块需求文档
## 1. 模块概述
负责生产过程中的数据实时采集，包括人员报工、产量填报、工艺参数上报、异常上报，数据自动同步到电子批记录和SAP，确保生产数据的真实、准确、可追溯。

## 3. 核心流程
### 3.1 报工流程
1. 生产人员扫描派工单二维码
2. 系统校验工单状态、人员权限、前工序状态
3. 校验通过后进入报工页面
4. 填写产量、工艺参数、异常情况（如有）
5. 提交报工
6. 车间主管审核报工数据（可配置是否需要审核）
7. 审核通过后系统自动同步数据到电子批记录、SAP、WMS
8. 若为最后一道工序，自动触发生成入库单
### 3.2 异常上报流程
1. 生产过程中发现异常，点击异常上报按钮
2. 填写异常类型、描述，上传图片/视频附件
3. 提交异常工单，系统自动派发给对应负责人
4. 负责人收到通知后处理异常
5. 处理完成后反馈处理结果，关闭异常工单
