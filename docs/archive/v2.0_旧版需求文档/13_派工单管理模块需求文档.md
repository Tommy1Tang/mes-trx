# 派工单管理模块需求文档
## 1. 模块概述
派工单是各工序生产执行的核心依据，负责派工单模板配置、派工单生成、人员关联、状态全生命周期管理，支持各工序自定义所需字段，满足不同工序的个性化需求。

## 3. 核心流程
### 3.1 派工单生成执行流程
1. 排产计划确认下发
2. 系统根据工序模板自动生成各工序派工单
3. 生成唯一二维码，打印派工单（可选）
4. 生产人员扫码关联人员和工单，确认开工
5. 系统自动记录开工时间，开始计时
6. 生产过程中填报实绩参数、异常情况
7. 生产完成后扫码报工，确认完工
8. 系统自动记录完工时间，统计工时，更新工单状态为已完工
