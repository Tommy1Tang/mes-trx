# SQL变更脚本目录

## 说明

本目录用于存放MES系统所有数据库变更脚本（DDL）。

## 命名规范

脚本命名格式：`YYYYMMDD_描述.sql`

示例：
- `20260430_新增班次主数据表.sql`
- `20260430_生产工单表新增紧急程度字段.sql`

## 脚本要求

1. **必须包含回滚语句**：每个脚本末尾必须包含 `-- ROLLBACK` 注释的回滚语句
2. **必须包含变更说明**：脚本开头必须注释说明变更内容、原因、影响范围
3. **必须包含变更编号**：关联 `05_Change_Log.md` 中的变更编号
4. **必须在测试环境验证**：生产环境执行前必须在测试环境验证通过

## 脚本模板

```sql
-- ================================================
-- 变更编号：DM-YYYYMMDD-序号
-- 变更类型：新增表/新增字段/修改字段
-- 变更描述：XXX
-- 变更原因：XXX
-- 影响范围：XXX
-- 执行人：XXX
-- 执行日期：YYYY-MM-DD
-- ================================================

-- 正向变更脚本
CREATE TABLE pro_xxx (
    ...
);

-- ROLLBACK 回滚脚本
-- DROP TABLE pro_xxx;
```

## 注意事项

- 涉及业务数据变更的脚本必须经过DBA评审后才能执行
- 生产环境执行脚本前必须在测试环境验证通过
- 脚本执行后必须更新 `05_Change_Log.md` 变更记录
